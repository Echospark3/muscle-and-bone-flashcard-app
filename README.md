# muscle-and-bone-flashcard-app
### Purpose
- flashcards made to educate people about human muscle and bone anatomy
### Features

- program loads cards
- gives the user options to revise infomation flashcards 
- after revision is complete asks user if they want to do a quiz or a test(test records score)
- records score in documents
